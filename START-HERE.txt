KITCHEN CONFIGURATOR - run it on your computer
==============================================

1. Install Python 3.8 or newer (once)
   Windows: https://www.python.org/downloads/  - tick "Add python.exe to PATH"
   macOS:   https://www.python.org/downloads/  (or run: xcode-select --install)
   Nothing else is needed: no internet, no npm, no extra packages.

2. Start it
   Windows: double-click  "Start Kitchen Configurator.bat"
   macOS:   double-click  "Start Kitchen Configurator.command"
            (first time: right-click > Open, then Open, if macOS warns you)
   Linux:   ./start.sh
   Your browser opens at http://localhost:8000 (the next free port if 8000 is taken).
   Keep the black console window open while you work; close it to stop.

3. Build in Archicad (optional)
   - Install the Tapir add-on for your Archicad version:
     https://github.com/ENZYME-APD/tapir-archicad-automation/releases
   - In the web app: Send to Archicad > Download build file.
   - In Archicad (a project open): run archicad/KitchenBuild.py from Tapir's
     script palette, or double-click "Build in Archicad" (.bat / .command).
     The "Kitchen Configurator: Build Kitchen" window picks the build file up
     from Downloads. Check the story and origin ("From selected Zone" places it
     at a selected Zone), then press Build in Archicad.
   - Every element is verified by read-back. Replace removes only this
     script's own verified previous build, and keeps anything you edited.
   - Elements are placed on layers named "KITCHEN - ...". Builds are journalled
     in Documents/Kitchen Configurator/journal.

Troubleshooting
   - "Python was not found" on Windows: reinstall Python with "Add to PATH"
     ticked, or turn off the Microsoft Store "python" alias in
     Settings > Apps > Advanced app settings > App execution aliases.
   - Archicad not found: Archicad must be running with a project open (no
     dialog open) and Tapir installed; the script looks on ports 19723-19744.
   - Without Python you can still open index.html directly in a browser to
     design and export (JSON / CSV / PNG) - only "Send to Archicad" needs it.

Command line (optional)
   python3 serve.py --open                     start and open the browser
   python3 archicad/build_kitchen.py model.json --test   test placement
   python3 archicad/build_kitchen.py model.json          build an exported model
   See README.md for all parameters and details.
